\# Проект: LensTool

Настольная программа для Windows на C# (.NET LTS, WPF):

1\. Мгновенный перевод текста с экрана: горячая клавиша → выделение области → OCR → перевод → оверлей рядом с областью

2\. Поиск по картинке: горячая клавиша → выделение области → открыть поиск в браузере



\## Правила

\- Структура: Capture/, Ocr/, Translation/, ImageSearch/, UI/, Settings/

\- Интерфейсы ITranslator и IOcrEngine, чтобы движки можно было переключать

\- OCR по умолчанию: Windows.Media.Ocr

\- API-ключи не хранить в коде и не коммитить (user-secrets или переменные окружения)

\- Учитывать DPI и несколько мониторов при захвате области

\- Одно приложение в трее, одновременно только один экземпляр
